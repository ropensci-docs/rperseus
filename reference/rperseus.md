# rperseus: A package to obtain texts from the Perseus Digital Library

The package contains a catalog and a function. The catalog is
[`perseus_catalog`](https://docs.ropensci.org/rperseus/reference/perseus_catalog.md)
and can be perused to locate a particular text and its corresponding
URN. Then pass the URN to
[`get_perseus_text`](https://docs.ropensci.org/rperseus/reference/get_perseus_text.md)
to obtain the text.
